## Contenidos

1. **Introducción a los sistemas de comunicaciones** — modelo de un sistema de comunicación, teoría de la información (entropía, S/N, Shannon-Hartley), transmisión analógica/digital, modulaciones, multiplexación.
2. **Introducción a las redes de datos** — arquitecturas, modelos OSI y TCP/IP, Internet, organismos de normalización.
3. **Capa física: medios de transmisión** — cables, coaxiales, fibra óptica, inalámbrico, propagación e interferencias.
4. **Capa de acceso en redes locales** — métodos de acceso al medio, IEEE 802.3 y 802.11, NIC/Hub/Bridge/Switch/AP, 802.1Q, STP.
5. **Capa de interred** — direccionamiento IPv4/IPv6, VLSM, CIDR, ICMP, ARP, BOOTP, ruteo RIP/EIGRP/OSPF/BGP, ruteo entre VLANs.
6. **Capa de transporte** — TCP, UDP, NAT y PAT.
7. **Capa de aplicación** — DHCP, DNS, FTP, TFTP, SNMP, correo, WWW, VoIP, IoT, tecnologías móviles, QoS y control de congestión.

## Actividades prácticas

1. Medios físicos de comunicación
2. Análisis de tramas en capa 2 (OSI)
3. Introducción a capa 3 (OSI)
4. Ruteo interno dinámico y ruteo externo
5. Capa de transporte
6. Capa de aplicación
7. TP integrador final: análisis, diseño e implementación de una red de datos (grupal)
8. Trabajo grupal de investigación
